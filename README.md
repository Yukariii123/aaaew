# aaaew

A simple front-end web project built as a static website.

## Overview
This repository contains a small website built with HTML, CSS, and JavaScript. It is designed to be lightweight, easy to open, and easy to customize.

## Project structure
- `index.html` — main page
- `style.css` — page styling
- `script.js` — interactive behavior

## Run locally
1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Notes
This project is best suited for quick front-end experiments, personal landing pages, or simple website prototypes.
